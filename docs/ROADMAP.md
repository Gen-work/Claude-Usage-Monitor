# 展望与 TODO / Roadmap

[README](../README.md) · 中文为主，条目名附英文。

方向：保持简洁、可玩、默认少文字。常驻花瓣、输入光圈、发送圆环逐步成为三个**不同层级**的视觉指示；动效（呼吸、渐变、水墨、汽水、史莱姆、颜料水滴、棱镜……）是产品的一部分，不是装饰性附加。

两条数据原则贯穿所有条目：

- **不伪造数据。** 没有可靠来源时（上下文占用、Gemini 额度、账号气泡色），宁可不显示，也不用估算冒充实测。
- **不同预算不合并。** 5 小时额度和每周额度是两个预算，不能未经说明合成一个「总余量」。

### 调色盘 / Colour picker

保留现在简洁的渐变条，用动作和渐进展开说明「可拖、可点、可取色」。最小状态机：

| 状态 | 进入 | 呈现 | 数据 |
| --- | --- | --- | --- |
| 静止 | 未悬停 | 渐变条 + 中间色球 | 已提交颜色 |
| 可拖提示 | 移入色球 | 布丁般左右晃动 | 不变 |
| 轻触 | 持续悬停 | 色球略扁，像手指轻放在史莱姆上 | 不变 |
| 色环展开 | 稍延迟 | 按两端颜色计算的晕染色环，给出两端之间的和谐色 | 候选色，不提交 |
| 取色预览 | 移出色球进入光晕 | 放大镜 + 色号 + 当前语言的色名；颜料水滴 / 棱镜射线流向色球 | 预览；色名来源待定 |
| 按住 | 按下并保持 | 流速加快，色球闪烁对应颜色 | 保留原值以便取消 |
| 拖拽预览 | 按住移动 | 连续预览周围颜色 | 临时值，不逐帧写存储 |
| 取消 | 移出一定范围 | 收起反馈，恢复原色 | 丢弃 |
| 确认 | 有效范围内松手 | 色球与光晕落定 | 只提交最终色 |

待决定：拖中间色球调「过渡位置」与拖拽取色如何区分（例如前者限制在色条上，后者在展开的色环里）。
